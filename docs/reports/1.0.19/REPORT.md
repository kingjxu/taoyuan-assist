# 桃园助手 1.0.19：悬浮窗诊断与字号调整

## 修改
- 打开/返回主界面时，检测悬浮窗权限；未授权先显示助手内说明，提供“去设置”和“知道了”，不再无说明自动跳走。权限页打不开时回退应用详情页，再失败提示手动设置。
- 点击“进入”和录屏授权返回时再次检查权限，未允许时阻止继续启动。
- 新增 OverlayDiagnostics：私有持久化错误、限定包名广播；Activity 接收器使用 NOT_EXPORTED。前台收到错误立即显示，后台发生的错误在返回助手后显示，同一时间不重复堆叠悬浮窗诊断弹窗。
- 记录窗口创建失败、权限缺失、接收器初始化失败、前台服务启动失败以及 Activity 调用启动服务被拒绝。成功创建或用户确认后清除记录；失败提示停止录制并重新开始。
- 修复 addView 失败仍保留窗口引用的问题，只在成功后保存；失败停止悬浮窗服务，不无限后台重试。销毁时容忍窗口已被系统移除。
- 字号从24sp减至20sp，保留红色和加粗、Result过滤、初始“等待反馈”、5秒清空与新有效Result重置计时。
- versionName1.0.19、versionCode12、页面v1.0.19；Debug签名。
