# 桃园助手 1.0.23 客户端上传时延优化

## 变更

- 移除每个成功请求结束后的 1 秒节流等待；成功返回后，单一上传线程立即消费 `latest_frame` 队列中的最新帧。
- 保持单线程同步 HTTP 上传、容量 1 队列和旧帧替换回收语义，不增加并发请求或历史帧堆积。
- 连续上传失败时使用 250ms、500ms、1s、2s 的可中断退避，最大 2s；成功后清零。该退避只保护故障路径，不增加成功链路时延。
- JPEG 压缩和 Base64 流式写入仍留在上传线程。采集线程只负责取帧，避免编码阻塞采集以及为随后被替换的帧浪费 CPU。
- 版本更新为 `versionCode=16`、`versionName=1.0.23`，页面显示 `v1.0.23`。
